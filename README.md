# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh
AQUA-SAVE es un proyecto integrador de quinto semestre que tiene como objetivo crear una aplicación web interactiva para educar a los usuarios sobre la importancia de cuidar el medio ambiente, específicamente en temas relacionados con la contaminación por microplásticos y la acidificación de los océanos.

Puntos Principales de Funcionalidad
Crear una interfaz de usuario interactiva y atractiva para educar a los usuarios sobre problemas ambientales
Implementar un sistema de recompensas con monedas de oro para incentivar a los usuarios a completar tareas y aprender más sobre estos temas
Agregar más objetos y elementos interactivos a la aplicación para mejorar la experiencia del usuario
